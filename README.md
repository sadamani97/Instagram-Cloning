# 📸 Instagram Clone – React Project

A frontend-focused Instagram clone built using React that replicates core social media features such as stories, posts, profile management, and followers.

---

## 🚀 Features

- 📖 Stories with navigation
- 📰 Posts feed with likes & captions
- 👤 User profile management
- ➕ Follow / Unfollow users
- 🔀 Dynamic routing using React Router
- 🎨 Responsive UI using Bootstrap

---

## 🛠 Tech Stack

- React
- React Router DOM
- Axios
- Bootstrap
- REST APIs

## ⚙️ How It Works

- Fetches data from backend APIs using Axios / Fetch
- Uses React Hooks for state and lifecycle management
- Dynamic routing for stories and profiles
- Modular and reusable components
